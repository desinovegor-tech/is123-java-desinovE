# AvitoMini

AvitoMini — учебное web-приложение, представляющее собой мини-аналог сервиса объявлений Avito.

Проект разработан на языке Java с использованием Jakarta Servlets, JSP, JDBC и базы данных Firebird.

## Основные возможности приложения

- регистрация пользователей;
- авторизация пользователей;
- выход из аккаунта;
- просмотр объявлений;
- просмотр подробной информации об объявлении;
- создание объявлений;
- загрузка фотографий к объявлениям;
- просмотр своих объявлений;
- снятие объявления с публикации;
- добавление объявлений в избранное;
- удаление объявлений из избранного;
- оформление заказа;
- просмотр своих заказов;
- отмена заказа;
- обмен сообщениями между пользователями;
- просмотр и редактирование профиля.


### Назначение основных пакетов

```text
controller — сервлеты, которые обрабатывают HTTP-запросы

```

## Используемые паттерны проектирования

В проекте используются три паттерна проектирования:

```text
1. Repository
2. Factory
3. Strategy
```

## 1. Паттерн Repository

Паттерн Repository используется для отделения логики работы с данными от сервлетов.

В проекте созданы три интерфейса:

```text
UserRepository
AdvertisementRepository
OrderRepository
```

Каждый интерфейс имеет три реализации.

### UserRepository

```text
JdbcUserRepository — работа с пользователями через базу данных
MemoryUserRepository — хранение пользователей в памяти
FileUserRepository — хранение пользователей в файле
```

### AdvertisementRepository

```text
JdbcAdvertisementRepository — работа с объявлениями через базу данных
MemoryAdvertisementRepository — хранение объявлений в памяти
FileAdvertisementRepository — хранение объявлений в файле
```

### OrderRepository

```text
JdbcOrderRepository — работа с заказами через базу данных
MemoryOrderRepository — хранение заказов в памяти
FileOrderRepository — хранение заказов в файле
```

## 2. Паттерн Factory

Паттерн Factory используется для создания нужной реализации репозитория.

В проекте создан класс:

```text
RepositoryFactory
```

Он позволяет получить нужную реализацию репозитория:

```text
JDBC
MEMORY
FILE
```

Пример назначения:

```text
если нужно работать с базой данных — используется JDBC-реализация;
если нужно хранить данные временно — используется MEMORY-реализация;
если нужно хранить данные в файле — используется FILE-реализация.
```

## 3. Паттерн Strategy

Паттерн Strategy используется для расчёта стоимости доставки.

В проекте создан интерфейс:

```text
DeliveryCostStrategy
```

И его реализации:

```text
PickupDeliveryStrategy — самовывоз
PostDeliveryStrategy — Почта России
YandexDeliveryStrategy — Яндекс Маркет
CdekDeliveryStrategy — СДЭК
```

Также создан класс:

```text
DeliveryStrategyFactory
```

Он выбирает нужную стратегию доставки в зависимости от выбранного пользователем способа доставки.

Стоимость доставки:

```text
Самовывоз — 0 рублей
Почта России — 350 рублей
Яндекс Маркет — 250 рублей
СДЭК — 500 рублей
```

## Слой Service

В проекте используется сервисный слой.

Класс:

```text
OrderService
```

используется для расчёта стоимости доставки и итоговой суммы заказа.

```text

FAVORITES
MESSAGES

```

### USERS

Таблица хранит информацию о пользователях:

```text
ID
LOGIN
PASSWORD
NAME
CITY
PHONE
```

### ADVERTISEMENTS

Таблица хранит объявления пользователей:

```text
ID

TITLE
DESCRIPTION
PRICE
CATEGORY_ID
STATUS
PUBLICATION_DATE
LOCATION
CONDITION
DELIVERY_METHOD
```

### ADVERTISEMENT_PHOTOS

Таблица хранит фотографии объявлений:

```text
ID
ADVERTISEMENT_ID
IMAGE_URL
SORT_ORDER
```

### ORDERS

Таблица хранит заказы:

```text
ID

BUYER_ID
ORDER_DATE

PAYMENT_METHOD
STATUS
TOTAL_AMOUNT
```

## Статусы объявлений

В проекте используются следующие статусы объявлений:

```text
active — объявление опубликовано
reserved — объявление зарезервировано после оформления заказа
archived — объявление снято с публикации
```

## Статусы заказов

В проекте используются следующие статусы заказов:

```text
pending — заказ оформлен
canceled — заказ отменён
```

## Безопасность

В проекте реализовано хеширование паролей пользователей.

Для этого используется класс:

```text
PasswordUtil
```

Пароль пользователя не хранится в открытом виде.  
В базе данных сохраняется хеш пароля с солью.

## Запуск проекта

1. Открыть проект в IntelliJ IDEA.
2. Настроить Apache Tomcat.
3. Подключить базу данных Firebird.
4. Проверить путь к базе данных в классе `DbUtil`.
5. Убедиться, что Firebird Server запущен.
6. Запустить проект на сервере Tomcat.
7. Открыть приложение в браузере.
